## 📌 О проекте

Идея проекта выросла из реального интереса — оценки бизнес-модели экспорта автомобилей из Кореи в Россию/Монголию. Задача:

1. Исследовать, от чего зависит цена подержанного авто в Корее.
2. Построить модель, предсказывающую цену по характеристикам объявления.
3. Определить, какие модели дают лучшее соотношение **спрос ↔ цена** для экспортной закупки.

> **Про данные:** используется синтетический датасет (2500 записей), сгенерированный с реалистичными распределениями цен/пробега/возраста, откалиброванными по порядку величины под публичные ориентиры корейского рынка (Encar, KB Chachacha). Это сделано осознанно для учебного портфолио-проекта — структура `src/generate_data.py` открыта, и данные легко заменить на реальный парсинг.

## 🤖 Модель

`RandomForestRegressor` внутри `sklearn.Pipeline` с `OneHotEncoder` для категориальных признаков (модель авто, тип топлива, коробка передач, регион, наличие ДТП).

| Метрика | Значение |
|---|---|
| MAE | **≈ 1.07 млн KRW** (~55 000 ₽) |
| R² | **0.976** |

## 💡 Главные выводы

- Цена сильнее всего зависит от **модели/бренда, возраста и пробега** — модель количественно подтверждает вклад каждого фактора.
- Автомобили с историей ДТП теряют в цене **больше**, чем можно было бы объяснить одним пробегом — важно фильтровать при отборе на экспорт.
- **Hyundai Avante, Ssangyong Torres и Kia Sportage** показывают лучшее соотношение экспортного спроса к цене — приоритетные кандидаты при ограниченном бюджете закупки.
- Модель (R² ≈ 0.97) может использоваться как быстрый ориентир «справедливой цены» при просмотре объявлений — помогает находить недооцененные варианты.

